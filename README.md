# جهاز حفظ ومراجعة القرآن الكريم | Quran Trainer

جهاز محمول يساعد على حفظ القرآن الكريم ومراجعته، مبني على **ESP32-S3** وشاشة لمس. يعرض الآيات بالعربية، ويتيح إخفاء الكلمات ثم كشفها تدريجيًا لاختبار الحفظ، مع حفظ موضع القراءة لكل سورة.

يعمل دون اتصال بالإنترنت، والنصوص والخط مضمّنة داخل البرنامج؛ لا يحتاج إلى بطاقة microSD أو هاتف أثناء الاستخدام.

## المميزات

- القرآن الكريم كاملًا: **114 سورة و6236 آية**، من الفاتحة إلى الاخلاص.
- واجهة عربية وقائمة لاختيار السور.
- وضع مراجعة لإخفاء الكلمات وكشفها كلمةً كلمة أو حتى نهاية الآية.
- تقسيم النص إلى شاشات تناسب حجم العرض، مع متابعة الآيات الطويلة.
- حفظ موضع مستقل لكل سورة، وزر لاستكمال آخر موضع.
- ثلاثة أحجام للخط، ومظهر فاتح وآخر داكن.
- التحكم بسطوع الإضاءة ومدة سكون الشاشة عبر الإعدادات.
- اختيار بدء القراءة بالنص ظاهرًا أو مخفيًا، وفتح القائمة أو الاستكمال عند التشغيل.
- معايرة اللمس وحفظ إعداداته.
- عرض نسبة البطارية تقديريًا من قياس الجهد.

> هذا الإصدار مخصص لعرض النص والمراجعة، ولا يتضمن تشغيل التلاوات الصوتية. صفحات العرض تتغير حسب حجم الخط، ولا تطابق صفحات المصحف المطبوع.

## المكونات

| المكوّن | المواصفات المستخدمة |
| --- | --- |
| المتحكم | ESP32-S3 N16R8، بذاكرة Flash سعة 16MB وPSRAM سعة 8MB |
| الشاشة | TFT بدقة 240×320 وواجهة SPI، بتعريف ILI9341 |
| اللمس | متحكم XPT2046 |
| الإضاءة | التحكم عبر GPIO4 حسب دائرة الإضاءة المستخدمة |
| قياس البطارية | بطارية ليثيوم خلية واحدة ومقسّم جهد بمقاومتين 10kΩ |

يعرض البرنامج الواجهة أفقيًا بدقة **320×240**. يوجد خيار لتعريف ST7789 داخل الكود؛ اختره فقط إذا كان هذا هو متحكم شاشتك.

## توصيل الشاشة واللمس

الأرقام التالية هي **أرقام GPIO**، وليست ترتيب الأرجل على اللوحة. افصل التغذية قبل تغيير الأسلاك.

| طرف الشاشة | ESP32-S3 |
| --- | --- |
| VCC | 3V3 |
| GND | GND |
| CS | GPIO10 |
| RESET / RST | GPIO8 |
| DC | GPIO9 |
| SDI / MOSI | GPIO11 |
| SCK | GPIO12 |
| LED | GPIO4، وفق توصيل دائرة الإضاءة |
| SDO / MISO | GPIO13 |
| T_CLK | GPIO12، مشترك مع SCK |
| T_CS | GPIO7 |
| T_DIN | GPIO11، مشترك مع MOSI |
| T_DO | GPIO13، مشترك مع MISO |
| T_IRQ | غير موصل |

أطراف قارئ microSD غير مستخدمة في هذا المشروع.

### إعداد الإضاءة

لتفعيل التحكم بالسطوع على GPIO4:

```cpp
#define BACKLIGHT_PWM_ENABLED 1
#define BACKLIGHT_PWM_INVERTED 0
```

طرف `LED` يختلف بين وحدات الشاشات؛ إذا كان يغذّي الإضاءة مباشرةً، استخدم دائرة قيادة مناسبة بدل تحميل GPIO بتيار الإضاءة. الإعداد `INVERTED` يعكس اتجاه PWM، ولا يفعّل التحكم بمفرده.

### قياس البطارية

لقياس بطارية ليثيوم خلية واحدة، بجهد اسمي 3.7V وجهد امتلاء 4.2V:

1. صِل مقاومة **10kΩ** من موجب دخل رافع الجهد `VIN+` إلى نقطة القياس.
2. صِل مقاومة **10kΩ** من نقطة القياس إلى سالب الدخل `VIN−`.
3. صِل نقطة القياس إلى **GPIO1**، مع أرضي مشترك للمتحكم والدائرة.

القياس يكون **قبل رافع الجهد** عند جهد البطارية، وليس من خرج 5V. يخفض المقسّم جهد 4.2V إلى نحو 2.1V عند GPIO1.

تتحدث القراءة كل خمس ثوانٍ مع تنعيمها لتقليل التذبذب. النسبة تقديرية، وليست قياسًا مباشرًا للسعة المتبقية، ولا تتضمن مؤشرًا لاكتشاف توصيل الشاحن. تظهر `--%` عند قراءة جهد خارج المجال المقبول.

## رفع البرنامج

### باستخدام Arduino IDE

1. ثبّت حزمة **esp32 by Espressif Systems** من مدير اللوحات. إعداد المشروع الأصلي يستهدف Arduino-ESP32 **2.0.17**.
2. ثبّت المكتبات:
   - Adafruit GFX Library
   - Adafruit ILI9341
   - Adafruit BusIO
   - XPT2046_Touchscreen
   - Adafruit ST7735 and ST7789 Library، عند اختيار ST7789
3. افتح `QuranTrainer.ino` من مجلد `QuranTrainer`، وأبقِ `quran_data.h` و`partitions.csv` بجانبه.
4. اختر **ESP32S3 Dev Module** واضبط:

   | الخيار | القيمة |
   | --- | --- |
   | Flash Size | 16MB |
   | Flash Mode | QIO |
   | PSRAM | OPI PSRAM |
   | تقسيم الذاكرة | ملف `partitions.csv` المرفق |
   | Erase All Flash Before Sketch Upload | Disabled للحفاظ على الإعدادات والتقدم |

5. تحقق من اختيار تعريف الشاشة وإعداد الإضاءة المناسبين، ثم اختر المنفذ وارفع البرنامج.
6. عند استخدام منفذ **UART** للرفع والمراقبة، اضبط `USB CDC On Boot` على **Disabled**. افتح Serial Monitor بسرعة **115200** عند الحاجة للتشخيص.

إذا توقف الرفع عند `Connecting`، اضغط مطولًا على `BOOT`، واضغط `RST` ثم اتركه، واترك `BOOT` بعد بدء الرفع.

### باستخدام PlatformIO

افتح المجلد الذي يحتوي على `platformio.ini` ثم نفّذ:

```bash
pio run
pio run --target upload
pio device monitor
```

ملف الإعدادات المرفق يحدد اللوحة والمكتبات وتقسيم الذاكرة.

## الاستخدام

1. عند أول تشغيل، اضغط علامات المعايرة التي تظهر على الشاشة.
2. اختر سورة من القائمة، أو اضغط **استكمال** للعودة إلى آخر موضع.
3. اضغط **ابدأ** لإخفاء الكلمات واختبار حفظك.
4. استخدم **الكلمة التالية** للكشف التدريجي، أو **كشف الآية** لإظهار بقية الآية الحالية.
5. استخدم **التالي** و**السابق** للتنقل، و**القائمة** للعودة إلى السور.

يحفظ الجهاز موضع العرض لكل سورة، لكنه لا يحفظ حالة الكلمات المكشوفة. بعد إعادة التشغيل، يحدد خيار بدء القراءة في الإعدادات ما إذا كان النص يظهر أو يبدأ مخفيًا.

عند سكون الشاشة، أول لمسة توقظها فقط؛ اللمسة التالية تنفذ الأمر.

## أوامر Serial Monitor

اضبط السرعة على **115200** وأرسل حرف الأمر:

| الأمر | الوظيفة |
| --- | --- |
| `k` | إعادة معايرة اللمس |
| `b` | فتح قائمة السور |
| `c` | الاستكمال |
| `n` | الجزء التالي داخل السورة |
| `p` | الجزء السابق داخل السورة |
| `h` | بدء المراجعة أو إعادة الإخفاء |
| `w` | كشف الكلمة التالية |
| `a` | كشف بقية الآية |
